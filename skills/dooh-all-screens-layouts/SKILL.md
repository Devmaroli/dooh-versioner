# DOOH All-Screens Layout Library (English + Arabic)

## How to use
1. Find the screen by name or by size in the index.
2. Use its layout as the starting grid. Every layout is a **starting point**: adjust for the real pixel pitch, physical size, seams, mounting height, and the brand's clear space.
3. For Arabic, use the AR column (x-positions are mirrored: x' = width − x). Mirror alignment, arrows, row order, and animation direction. Do not mirror the hero imagery, logos without an approved Arabic version, phone numbers, URLs.
4. If a screen is not listed, use the closest layout class below, or compute one with the same rules.
5. Screens with the same pixel size share one layout (marked "Same size as ...").

## Layout classes (rules used)
| Class | Ratio (w/h) | Layout logic |
|---|---|---|
| Ribbon | 5:1 and wider | One horizontal row: Logo, Headline (1 line), Hero, CTA. Margin 8% of height. Mirrored for Arabic (CTA first on the left, logo last on the right) |
| Wide | 1.25:1 to 5:1 | Split: text block (logo top, headline middle, CTA bottom) on one side, hero on the other. Mirrored for Arabic |
| Square | 0.85:1 to 1.25:1 | Centred stack: logo, headline, hero, CTA, legal. Equal margins on all sides |
| Portrait | 1:2.5 to 0.85:1 | Vertical stack with a support line; key message in the middle band |
| Tall | narrower than 1:2.5 | Vertical zones with eye-level band; top = brand only, base = legal and non-critical |

## Rules that apply to every screen
- Margins are about 7.5% of the shorter side (8% of height on ribbons). Recalculate; never reuse pixel gaps from another size.
- Logo keeps brand clear space and the same relative position in all formats and languages.
- CTA is the last thing the eye reaches (right end for English, left end for Arabic on horizontal layouts; lower part on vertical ones).
- Headline sizes and "chars/line" are rough estimates for Latin text (0.55 × font size per character; Arabic 0.50 × the larger Arabic size). If the copy does not fit, shorten it with the client's approval; do not shrink below the legibility minimum.
- Arabic type is 10 to 15% larger than English, leading 1.3 to 1.5, no letter-spacing, correct shaping, no italics.
- Never stretch the master. Recompose from layers; extend backgrounds or use cutouts on a colour field.
- Keep text and logo off seams and bezels. End frame must be static and complete.
- Check at 1:1 pixels, then at a scaled-down viewing distance, then on the player.
