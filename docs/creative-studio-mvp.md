# Creative Studio MVP

## Workflow
Import masters → inspect EN/AR mapping → adapt to screen presets → review → export PNG ZIP.

## Acceptance criteria
- Import PNG, JPG, SVG, PSD/PSB using existing engine.
- Support English and Arabic masters together, with filename-based language mapping.
- Preview extreme ribbon and tower formats without distorting aspect ratio.
- Preserve existing engine and tests.
- Distinguish preview-only controls from implemented rendering functionality.

## Out of scope
Semantic layer recognition, true optical centering, Adobe-editable export.
