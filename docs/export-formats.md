# Export formats

The Export stage offers PNG, PDF and PSD in the existing screen/language ZIP workflow. Each output is rendered sequentially at its actual preset dimensions from the approved screen-specific layout or approved family guide. No preview upscaling or lossy JPEG recompression is used. ZIP compression level 6, compressed PSD channels, tight transparent layer crops and lossless PDF image streams reduce file size without reducing pixel dimensions or precision. File size depends on source complexity; layered PSDs retain source assets and will usually be larger.

PNG optionally hides only the separate identified background. Foreground alpha is preserved. Flattened masters cannot have their background removed through this switch; the export reports that limitation. Transparent filenames include `_transparent`.

PDF is a one-page, lossless RGB image document with an alpha soft mask where needed. One pixel maps to one PDF point at 72 ppi. For dimensions beyond 14,400 points, UserUnit retains the pixel mapping. PDF is a visual delivery format: text/paths are not editable vectors, and physical print size is unspecified. The encoder uses existing fflate compression, with byte-correct stream lengths and cross-reference offsets; no additional dependency is required.

PSD contains independent adapted pixel layers, ordered groups, visibility, locks, links, blend modes and opacity. Opacity/blending are omitted from isolated pixel renders and written as native PSD properties, avoiding double application. Leaf masks, fill and supported effects are baked into adapted pixels. Group fill remains native. Non-neutral adjustment layers and group masks/strokes currently block PSD export with a recovery message; PNG/PDF remain available. The document composite matches the approved rendered output.

A hidden original-source folder retains the imported native PSD layer tree in its original coordinates, including embedded Illustrator/PSB data, native text and masks supported by ag-psd. It is separate from the adapted pixel stack. This does not reconstruct vectors or provide editable adapted Illustrator word paths. Unsupported Photoshop metadata may not round-trip through the parser. Inspect advanced effects in Photoshop before production. Non-PSD sources retain their original composite in the reference folder.
