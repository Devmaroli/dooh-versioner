# Layer blend modes and opacity

The focused editor's Layers panel contains 27 blend modes in six optgroups and decimal Opacity/Fill controls displayed as percentages. Select a source unit, background, source-traced border or folder. Mixed selections display mixed values. Reset restores imported appearance. The panel, constraints and renderer are connected; changes persist per guide, invalidate approval and participate in seven-action Undo/Redo.

`src/blending.js` exports normalization, labels, mode groups, pure RGB/RGBA math and `compositeDraw`. Source alpha is multiplied by opacity. For opaque bottom pixels in Normal mode: `result = source * opacity + backdrop * (1 - opacity)`. General source-over also accounts for both source and backdrop alpha. Multiply uses `b*s`, Screen uses `1-(1-b)*(1-s)`, and Linear Dodge clamps `b+s` to 1 (normalized channels). Nonseparable modes use luminosity/saturation helpers. Dissolve uses a deterministic position hash. Native Canvas modes use bounded compositing; remaining modes process 256×128 pixel tiles with the same alpha math.

PSD parsing retains source blend, opacity, fill, group properties, mask references and locks. Individual sources blend against the actual backdrop rather than flattening the operation prematurely into an isolated transparent image. The panel compositor isolates folders where needed and handles Pass Through, group opacity, masks, inner stroke, fill and neutral-by-default Brightness/Contrast adjustments. It uses the same path for preview and production-resolution PNG output. See [layers-panel.md](layers-panel.md) for implementation, tests and fidelity limits.

The dedicated browser tests compare actual Canvas RGBA values for all 27 modes against the numerical implementation; import a generated PSD with Screen/50%; check all dropdown options; exercise endpoints, Linear Dodge, Undo/Redo, reset and refresh; and decode a downloaded production PNG to compare its pixels with the preview. Small 8-bit rounding differences are permitted. These checks do not establish complete Photoshop colour-management or PSD-effect parity.

References: [W3C compositing and blending equations](https://www.w3.org/TR/compositing-1/#blending), [Adobe blend mode descriptions](https://helpx.adobe.com/in_hi/photoshop/desktop/repair-retouch/adjust-light-tone/blending-mode-descriptions.html), [Adobe layer opacity and group Pass Through](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/apply-layer-effects/set-layer-opacity-and-blending-modes.html).
